# QL_Spem_Keyboard

Recreation of the mechanical keyboard for Sinclair QL computer by brand Spem

# WARNING: DO NOT USE THIS PROJECT IS NOT TESTED AND MISSING THINGS

Spem SRL, a italian company manufacture in 1986 a conversion kit for the Sinclair QL, named "System 2",
This include a aluminium desktop case with space for up to two 3 1/2" drives, the QL original Power supply and a Sinclair QL main board, to create a complete moderm desktop computer.

The case also incorporate a backplane where you can install a memory expansion and a disk interface.

The System 2 come with a full mechanical Keyboard, including numeric keys and 10 function keys, Spem use a unique aproach, and instead to provida a normal PC keyboard with a DIN-5 conector, design a specific one that connect directly to the keyboard conectors of the original Sinclair QL, and provide the aditional keys.

This is easy identificable because of the 20 cores ribbon cable the go from the keyboard to the case.

This project try to recreate this keyboard as identical as possible.
 
# Technical Details

The keyboard use keyswitch from Japanesse brand Futaba, referene MA-41 "Tombstone" because the top of the key is similar a tomb stone, with a cross emboss in the middle, while today's tipical keyswitchs the cross raise over the key.

This keyswitch has 3 legs, 2 of they are probably internally conected, to facilitate the develop of matrix keyboards using only 1 side of the PCB.

The combinations of keys need for some keys, like the F-5 F-10 that are really F1 to F5 at same time that shift keys, are from a pair of IC of type 4066, that are integrated analog swites, to power this 2 ic a small circuit drain the power from the keyboards lines itself.
